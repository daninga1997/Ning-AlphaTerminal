# 深圳主板股票搜索设计

## 目标

让用户可以在 Alpha Terminal 中按名称或代码检索深圳主板股票，而不改变现有 20 只核心观察池的批量策略、报告和交易边界。

## 范围

- 仅支持 `000`、`001`、`002` 开头且存在于本地深圳主板股票目录中的代码。
- 支持名称模糊匹配和完整六码代码匹配。
- 支持打开外部股票的研究详情，并按需获取真实报价和已有的历史数据能力状态。
- 搜索结果可明确加入“我的观察”，该动作不自动加入 20 只核心策略观察池。

## 非范围

- 不支持沪市、创业板、科创板、北交所或港股。
- 不对外部搜索股票自动生成买入信号、交易计划、报告排名或批量刷新任务。
- 不修改评分规则、策略规则、交易记忆、Dashboard 或现有核心观察池范围。

## 架构

### 股票目录

新增只读本地深圳主板股票目录，记录 `code`、`name`、`exchange` 与目录版本。目录仅用于检索、代码校验和显示名称；不承载实时价格或策略评分。

### 搜索服务

搜索 API 接收关键词，先标准化输入，再在本地目录进行精确代码匹配和名称包含匹配。返回数量限制、空结果和不支持市场的明确状态，不把上游异常或敏感配置暴露给页面。

### 研究详情

外部股票详情是“研究模式”：显示实时行情是否可用、日线/分钟线能力与更新时间。详情使用按需请求，失败时呈现不可用或过期状态，绝不以 Mock 数据伪装真实行情。

### 交易边界

20 只核心池继续是唯一可进入既有批量策略引擎的股票范围。外部股票即使报价可用，也不得显示策略 buy、生成交易计划或写入策略报告。加入“我的观察”只保存用户兴趣，不改变策略引擎白名单。

## 数据流

`搜索框 -> 本地目录 -> 搜索结果 -> 按需报价/历史数据 -> 研究详情`。

核心池的既有数据流维持不变：`20 只核心池 -> 批量行情 -> 数据完整性判断 -> 策略引擎 -> 报告/交易计划`。

## 失败处理

- 关键词为空：不查询，提示输入代码或名称。
- 不属于深圳主板：返回不支持提示。
- 目录无匹配：返回“未找到深圳主板股票”。
- 报价失败：保留最后成功缓存并标记 stale；无缓存时显示不可用。
- 日线或分钟线不可用：保留真实报价状态，但明确技术确认不足，禁止策略买入结论。

## 验收与测试

- 代码和名称均可检索到目录内股票。
- 沪市与创业板代码被明确拒绝。
- 外部股票研究详情不进入策略引擎、不产生 buy 或交易计划。
- 核心 20 只的观察池、报告、评分和批量刷新行为不变。
- 搜索、目录校验、研究模式边界和失败状态有单元或路由测试。
